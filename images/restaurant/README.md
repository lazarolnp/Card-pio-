# Fotos do restaurante

Pasta para fotos reais do ambiente do Paladino (fachada, salão, área externa) usadas na seção "Sobre" e como imagem de compartilhamento (Open Graph).

Para reativar a prévia de compartilhamento em redes sociais, adicione uma foto real em `images/restaurant/paladino-og.jpg` (recomendado 1200x630px) e inclua de volta no `index.html`:

```html
<meta property="og:image" content="images/restaurant/paladino-og.jpg">
```

Não foi incluída antes por não haver, no momento, uma foto real disponível — para não usar uma imagem genérica ou gerada por IA no lugar do restaurante real.
