# Fotos dos pratos

Esta pasta não contém fotos ainda — o ambiente usado para montar este site não teve acesso à internet para baixar as fotos reais do Paladino (ver nota no README principal).

Para ativar uma foto, basta salvar o arquivo com o nome exato do prato (o "id" usado em `js/main.js`) em formato `.jpg`, por exemplo:

```
images/dishes/carne-de-panela.jpg
images/dishes/pastel-de-angu.jpg
images/dishes/peixinho-no-fuba.jpg
```

O site detecta a foto automaticamente: se o arquivo existir, ele aparece no card e no modal do prato; se não existir, o card continua bonito com o design tipográfico atual (sem quebrar o layout).

Use fotos reais dos pratos do Paladino (nunca fotos genéricas de banco de imagens ou fotos geradas por IA, para não representar errado o que a casa realmente serve). Recomendado: JPG otimizado, proporção 4:3, até ~200KB por imagem.
